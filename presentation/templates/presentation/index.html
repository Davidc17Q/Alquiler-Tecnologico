Panel de pruebas rápida de la API

Usa este pequeño frontend para probar los flujos de negocio de TechRent sin necesidad de Postman. Internamente, esta página solo llama a la API REST: toda la lógica de negocio vive en la Service Layer, siguiendo principios de arquitectura limpia.

/api/v1/usuarios/ Crea usuarios
/api/v1/equipos/ Lista equipos disponibles
/api/v1/alquileres/ Crea un alquiler validando fechas y disponibilidad
/api/v2/pagos/ Confirma el alquiler a través de la pasarela de pago

Estado de la arquitectura

  • Service Layer: toda la lógica de negocio (validaciones, reglas de estado, cálculo de costo) vive en application/services.
  • Builder: la construcción de Alquiler se orquesta con AlquilerBuilder, encapsulando el cálculo de costo_total.
  • Factory: PaymentGatewayFactory selecciona StripePaymentGateway o FakePaymentGateway según configuración, sin romper DIP.
  • Preparado para API Gateway: la API REST es fina y desacoplada, lista para ser expuesta a través de un API Gateway o BFF.

2. Ver equipos

Aún no se han cargado equipos. Haz clic en "Cargar equipos".

3. Crear alquiler

Este flujo valida disponibilidad, coherencia de fechas y calcula el costo usando el AlquilerBuilder.

4. Confirmar pago

El pago confirma el alquiler cambiando su estado a PAGADO. Este paso se atiende en el microservicio Flask (Strangler) detrás de /api/v2/pagos/.

Esta página es solo una fachada fina: toda la lógica de negocio (reglas de fechas, estados, validación de disponibilidad, cálculo de costo y orquestación de pagos) reside en la capa de aplicación, respetando SRP y DIP.
